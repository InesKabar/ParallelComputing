# ParallelComputing

A Python project demonstrating parallel computing and thread synchronization using the Producer-Consumer pattern.

## Project Overview

The project uses multiple threads to simulate a producer and a consumer sharing a common buffer.

Semaphores are used to synchronize access to the shared memory and control the number of available and occupied buffer positions.

The producer generates 20 items, while the consumer retrieves and processes them.
